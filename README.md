# ZENTRO GARAGE 🚗

Bienvenue dans **ZENTRO Garage**, le garage automobile 3D du projet ZENTRO.

## 🚘 Concept

ZENTRO est un projet de jeu automobile avec :

* voitures sportives
* garage 3D
* personnalisation
* conduite
* courses
* missions
* ville ouverte
* collection automobile

## 🏁 Première voiture

La première voiture de démonstration est inspirée de la :

**Volkswagen Golf R 2025 Black Edition**

Le modèle actuellement présent dans la V1 est un modèle 3D temporaire créé avec Three.js.

## 🎮 Contrôles

* 🖱️ Clic gauche + déplacement : tourner autour de la voiture
* 🖱️ Molette : zoom
* `ESC` : fermer les menus

## 🛠️ Technologies

* HTML
* CSS
* JavaScript
* Three.js
* GitHub Pages
